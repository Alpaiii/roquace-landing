14. FAQ

Template

Can I customize the template?

Yes. The templates are provided with source code and can be customized according to your needs.

What technologies do you use?

Our templates may use technologies such as Next.js, Astro, TypeScript, and Tailwind CSS depending on the product.

Do I get the source code?

Yes, source code is included according to the template license.

Can you customize a template for me?

Yes. You can purchase a template and request customization through our website development service.

Website Service

How long does a website take to build?

Project duration depends on the scope and complexity of the website.

Can you build a website from scratch?

Yes. We can create a website based on your brand, requirements, and business goals.

Do you provide hosting?

Hosting and deployment can be discussed as part of the project.

Can I request specific features?

Yes. Custom functionality can be discussed during the project discovery process.

28. Final Product Definition

ROQUACE MVP adalah single-page marketing website berbasis Next.js yang memperkenalkan dua produk utama:

1. Website Templates

Template siap pakai yang dapat dibeli melalui platform eksternal.

2. Custom Website Development

Jasa pembuatan website yang menghasilkan leads melalui WhatsApp, email, atau external form.

Tidak ada backend dan database pada MVP.
